НАЧНИ ЗДЕСЬ — создай свою версию навыка Яндекс Алисы

Рекомендуемый путь: скопируй исходный репозиторий кнопкой Fork в свой GitHub. Своя копия принадлежит тебе: можно менять код, добавлять функции и развивать проект отдельно от первоисточника.

ПОЛНЫЙ ГИД
Открой README.md в репозитории:
https://github.com/ruslanpodzorovraw-collab/alice-gemini-serper-template

КОРОТКИЙ ПЛАН
1. На GitHub открой первоисточник и нажми Fork.
2. Импортируй свою копию в Vercel: Add New… → Project.
3. В Vercel → Settings → Environment Variables добавь GEMINI_API_KEY из Google AI Studio. Это единственный обязательный API-ключ.
4. По желанию добавь SERPER_API_KEY для интернет-поиска.
5. По желанию создай базу в Upstash и добавь UPSTASH_REDIS_REST_URL и UPSTASH_REDIS_REST_TOKEN для долговременной памяти.
6. Сохрани переменные, сделай Redeploy и дождись статуса Ready.
7. Скопируй домен Vercel, добавь /api и укажи адрес как Webhook URL в настройках навыка Яндекс Диалогов.
8. Проверь навык во встроенном разделе Тестирование Яндекс Диалогов.

Память Upstash сохраняет до 500 последних сообщений максимум на 30 дней. Её можно очистить фразой «Забудь наши прошлые диалоги». Без двух переменных Upstash навык продолжает работать с краткой историей Яндекса.

API-ключи и токены храни только в настройках Vercel. Не загружай их в GitHub и не пересылай в сообщениях.

Node.js нужен только если ты хочешь менять код и запускать тесты; для настройки Vercel и проверки в Яндекс Диалогах он не требуется.
